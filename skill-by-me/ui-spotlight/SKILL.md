# UI Spotlight

识别用户截图中指定功能或按钮的位置，并在图上高亮标注。

## 核心原则（重要）

- **单步直达**：观察图片后直接估算坐标并单步执行脚本，**严禁编写任何辅助测试脚本去探测像素或二次验证**。
- **容许目测误差**：标注只需圈出大致区域即可，有适度误差完全可以接受。
- **无需持久化存储**：脚本在临时目录生成并直接弹出预览，大语言模型无需将图片复制或保存到其他目录。

## 工作流程

1. **识别坐标**：凭视觉直觉直接估算目标控件的归一化坐标 `[ymin, xmin, ymax, xmax]`（数值范围 0~1000）。
2. **运行标注脚本**（一步完成）：
   - **优先方式（推荐）**：使用用户粘贴/上传时系统提供的图片路径：
     ```bash
     <Python 解释器路径> <skill_dir>/scripts/annotate.py --image "<图片路径>" --box <ymin> <xmin> <ymax> <xmax>
     ```
   - **备用方式（剪贴板模式）**：当且仅当无法获取图片本地路径时使用：
     ```bash
     <Python 解释器路径> <skill_dir>/scripts/annotate.py --clipboard --box <ymin> <xmin> <ymax> <xmax>
     ```
3. **反馈用户**：用一两句话简明说明该功能在界面的位置，并告知标注窗口已在屏幕上弹出。
